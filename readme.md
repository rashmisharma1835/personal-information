# Personal Information Program

## Description
This is a simple Python program that accepts a user's basic personal information and displays it in a clean, formatted profile summary. It helps beginners understand core programming concepts like variables, user input, and string formatting.

## Objectives
* Learn and practice Python variables.
* Take user input using the `input()` function.
* Perform type conversion (e.g., converting string to integer or float).
* Use f-strings for clean and formatted output.
## Tools & Technologies Used
* Python
* VS Code

## How to Run the Program
1. Open your terminal or command prompt in VS Code.
2. Run the program using the following command:
   ```bash
   python information.py
